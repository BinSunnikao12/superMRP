## 0. 一句话定位

**MVP-1（1 个月内）**：单据点、单层 BOM、静态数据 → 跑通 MRP 核心算法 → Web 端展示净需求表。

**目标人群**：1 个据点的计划员，手动上传 Excel 主计划 + 静态基础资料，点击"运行 MRP"，看到净需求结果。

## 1. MVP-1 范围（1 个月内必须完成）

### 1.1 项目一个段最关的 `MRP 算型最小核心`

#### 输入
- **主计划 A**：Excel 导入（料件、数量、开工时间）
- **BOM**（静态，手动录入或 JSON 导入）：父子物料 + 用量
- **基础资料**（静态，1 个 JSON 文件）：料件 → 补给策略、采购单位批量、最小起购量、提前期
- **库存**（手动录入）：静态可用库存
- **在制**（手动录入）：静态未完工量
- **多角在途**（手动录入）：静态未入库量

#### 输出
- **净需求表**（1 案 料件）：净需求数量、开工时间、完工时间、补给策略、建议动作（工单/请购单/委外单）

#### MVP-1 限制
- **只 1 个据点**（默认 LG）
- **BOM 最多 3 层**（A→B→C，不再高阶）
- **A=10个以下子件**（例: A=10, B=10x10=100, C=1000）
- **总料件 < 5000**
- **不需要 T+1 走批**（手动点“运行”）
- **不需要对接鼎捷/MES**（全部手动输入）

### 1.2 核心算法实现清单

实现以下公式（来自文档 2）：

```typescript
// 3.4.1 时间倒推
预计开工时间 = 预计完工时间 - 生产提前期/采购提前期
预计完工时间（头层） = 主计划开工时间
预计完工时间（下阶） = 上一层开工时间

// 3.4.2 净需求计算
净需求[头层] = 毛需求 - 领用在制 - 库存 - 多角在途
净需求[下阶] = 上层净需求 x BOM用量 - 领用在制 - 库存 - 多角在途

// 3.4.3 批量规则
净需求 = ceil(需求量 / 采购单位批量) x 采购单位批量   // 50 -> 150
净需求 = max(需求量, 最小起购量)                      // 小于500按500

// 3.4.4 自制优先级
	for each 自制物料:
		优先匹配在制工单余量
		剩余部分按 BOM 向下分解
```

### 1.3 技术选型（春节前打完）

| 类别 | 选型 | 理由 |

### 1.5 Web 端 3 个页面

1. **主计划上传页（UploadMasterPlan）**
   - 拖拽 Excel → 预览 → 提交
   - 上传后生成料件 A 的时间序列

2. **MRP 运行页（MRP）**
   - 显示已上传的主计划
   - 查看 / 编辑 BOM、基础资料、库存、在制
   - 点击「运行 MRP」按钮 → 后端计算 → 跳转到结果页

3. **净需求结果页（MRPResult）**
   - 表格展示：料件 / 层级 / 毛需求 / 净需求 / 开工时间 / 完工时间 / 补给策略 / 建议动作
   - 支持导出 CSV

## 4. 算法例子（验收用）

来自文档 2 原文，必须能在 MVP-1 复现：

```
输入:
  A = [{数量:100, 开工时间: 2026-08-01}]
  BOM: A -> B(1) + C(1.5) + D(2)

  基础资料:
    B: 自制, 生产提前期 = 7d
    C: 自制, 生产提前期 = 7d
    D: 外购, 采购单位批量 = 150, 采购提前期 = 14d
    E: 外购, 最小起购量 = 500

  库存: B=50, C=50, D=100, E=0
  在制: B=20(工单余量), C=30(工单余量)

输出:
  头层:
    B 毛需求=100, 净需求=100-0-50-0=50, 自制优先匹配在制 20 -> 剩余 30
       开工时间 = 2026-08-01 - 7d = 2026-07-25 - 7d = 2026-07-25
    C 毛需求=150, 净需求=150-0-50-0=100, 自制优先匹配在制 30 -> 剩余 70
       开工时间 = 2026-07-25
    D 毛需求=200, 净需求=200-0-100-0=100, 批量修正 = ceil(100/150)*150 = 150
       开工时间 = 2026-08-01 - 14d = 2026-07-18

  下阶 (BOM 未提供, 暂不展)
```

验收: 跑这个例子，结果必须与上面一致。
