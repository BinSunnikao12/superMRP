# 拉取日志分页设计

## 目标

解除日志接口固定返回最近 20 条的限制，同时避免一次加载全部历史记录拖慢 Admin 页面。

## 方案

- 日志接口接受 `page`、`pageSize`、`site`、`status`、`api` 参数。
- 每页允许 20、50、100 条，服务端最大限制为 100 条。
- 查询条件使用参数化 SQL；基地和状态先经过白名单校验。
- 接口返回日志、总条数、当前页、每页条数和总页数。
- 页面提供基地、状态、接口关键字筛选以及首页、上一页、下一页、末页按钮。
- 表格补充分页页数字段，错误摘要显示 120 字，完整错误通过单元格提示查看。

## 验证

- 验证默认 50 条、第二页 20 条和失败日志组合筛选。
- 验证非法状态返回 HTTP 400。
- 运行 TypeScript 构建、ESLint 和差异格式检查。
