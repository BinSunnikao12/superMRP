# BOM 逐层钻取与分页设计

## 目标

从净需求物料编码进入 BOM 结构，按层查看直接子件，并支持大 BOM 分页、逐级深入、刷新和返回。

## 交互

- 双击净需求表的产品编码，进入独立 BOM 路由。
- 当前页只查询一个主件的直接子件，显示项次、子件、名称规格、组成用量、单位和类别。
- 有下阶结构的子件可双击或点击“展开下一级”；叶子物料明确标识且不会继续跳转。
- 层级路径保存在路由 `trail` 参数中，页面显示可点击面包屑。
- 每层可选择 20、50、100 条，并支持首页、上一页、下一页和末页。

## 数据接口

`GET /api/admin/bom/children` 按 `site + main_part` 查询 `raw_bom`，关联 `raw_items` 中文名称，并通过同基地子件是否再次作为主件判断其是否可继续展开。接口返回总数、总页数、数据快照时间和主件信息；基地、料号和分页参数均校验。

## 验证

LG 产品 `1.101.103.00-US103-002` 实测 56 个直接子件，共 3 页；第一页和第二页各返回 20 条，非法基地返回 HTTP 400。当前 1000 条样本没有形成连续父子链，全量 BOM 同步后下阶识别会自动生效。
