# MRP 全量实时预览与新鲜度设计

## 目标

取消净需求预览的 100 条上限，让物料数量和需求汇总来自当前基地的全部 MySQL 数据，并清楚标记计算结果的新鲜度。

## 实现

- 删除预览接口的 `limit` 参数和 SQL `LIMIT`，全部物料参与排序、汇总和返回。
- `materials`、毛需求、净需求和缺料物料数均基于完整结果集。
- 响应增加本次计算完成时间、计算耗时和数据快照时间。
- 数据快照时间取需求、库存、在制、特殊供给、安全库存、在途、在验及物料主数据中该基地最新的 `pulled_at`。
- 页面将计算完成时间、耗时和快照时间展示在净需求标题下方，并标记为“全部物料实时计算”。

## 验证

LG 实测返回 3132 个物料、721 个缺料物料，完整计算耗时约 166ms，结果不再固定为 100；同时验证页面内嵌脚本语法、TypeScript 构建和类型检查。
