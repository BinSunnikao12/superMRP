# MRP 数值公式悬停说明设计

## 目标

让计划人员无需离开净需求表格即可确认每个数字的计算方式、代入值和数据来源。

## 实现

- 可解释数字使用虚线下划线和帮助光标标识。
- 页面只维护一个浮动提示框，通过事件委托响应汇总卡片和数千个明细单元格，避免为每个数字注册监听器。
- 四个汇总指标显示聚合公式、涉及的来源表和最终结果。
- 明细数量显示本料号公式、来源表字段和结果。
- 净需求显示本行实际代入式，例如 `MAX(0, 144600 + 0 - 0 - 0 - 0) = 144600`。
- 在途和在验明确提示“仅展示、暂不抵扣净需求”。

## 验证

LG 全量结果生成 3132 行净需求解释；首行净需求说明为 `MAX(0, 144,600 + 0 - 0 - 0 - 0)`，来源和结果属性正确。通过页面脚本语法、TypeScript 构建及类型检查。
