# Python APS 更新记录（2026-08-04）

基线提交：`56bad34 更新：同步最新 Python APS 业务逻辑`

## 有实际业务影响的变化

- 计算供给从 `gd01()` 切换为新方法 `get_special_supply()`。
- 特殊供给纳入 `GD04/GD01/GD30/GD16`，按料号汇总未完成量。
- 原 `gd01()` 的单别调整为 `GD16/GD35/GD36/GD15`。
- `gd_bom()` 新增排除 `GD20`。
- 采购订单的 PSCC 站点过滤字段由错误的 `PSCDSITE` 修正为 `PSCCSITE`。
- 生产单位批量继续固定为 `1`，注释明确其用途是取消批量限制但保留小数向上取整。
- 越南语“需求计算方式”翻译修正；越南采购需求 Sheet 后缀缩短为 `chi tiết`。
- 入口当前仅执行 LG，YN/QU/GX/FN 仍被注释。
- Python 包导入路径改动较大：部分模块改用 `aps.*`，Excel 又使用顶层 `compute/data`，运行目录仍会影响导入。

## 主要非业务变化

- 删除三个空 `__init__.py`。
- 大量说明性 docstring、注释和格式化内容被移除或回退。
- 加回了一批被注释的调试/备用代码，但未进入实际执行路径。

## 检查中发现的问题

- `needfunc()` 中出现中文逗号 `qpa分子，sfba011`，会造成 Oracle SQL 语法错误；后续实现提交已修正为英文逗号。
- 数据库账号密码仍硬编码，HTML 分析报告指出的安全风险仍成立。
- HTML 报告把 FN 标为“奉化”，但代码又对 FN 启用越南语字段，站点中文名称不能仅凭报告确认。
- HTML 报告生成于 Windows 路径，架构和算法说明仍有参考价值，但接口数量、LowCode 分页和 Node.js 本地快照机制已经过时。
